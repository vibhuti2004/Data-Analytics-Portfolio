# Sales Data Analysis Project

## Project Overview
This project focuses on analyzing sales data to understand business performance, customer behavior, product category performance, and regional sales trends.

The main objective is to clean, process, analyze, and visualize sales data to generate meaningful business insights and support better decision-making.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Microsoft Excel
- Power BI

## Dataset Information
- Total Orders: 5,000
- Total Customers: 989
- Total Quantity Sold: 20,224
- Product Categories: Beauty, Clothing, Electronics, Home
- Regions: East, North, South, West
- Data Period: 2022–2025

## Project Workflow
1. Data Collection
2. Data Understanding
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Excel Analysis
7. Power BI Dashboard Development
8. Business Insights and Reporting

## Key Business Insights
- Total Revenue: 5.11 Million
- Total Orders: 5,000
- Electronics generated the highest revenue among all product categories.
- Beauty generated the lowest revenue among all product categories.
- West was the highest-revenue region.
- East was the lowest-revenue region.
- South had the highest average delivery time.
- Average Customer Rating: 2.97 out of 5.
